# JSK ERP

JSK ERP is a Laravel-based system for managing overseas recruitment and visa processing — tracking candidates from passport collection through MOFA, visa management, embassy handover, manpower processing, and final delivery.

## Features

- **Project Management** — create and track recruitment projects by country, company, and profession
- **Candidate Collection** — record candidate details, passport info, and interview data
- **Passport Entry & Ready Tracking**
- **MOFA Section Processing**
- **Visa Management**
- **Embassy Section**
- **Manpower Processing**
- **Flight & Delivery Tracking**
- **Agency & Company Management**
- **User Management** with roles and soft deletes
